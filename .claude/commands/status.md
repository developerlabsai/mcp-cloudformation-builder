# Project Status

Show the current status of the MCP CloudFormation Builder project.

## Check and Report:

### Git Status
- Current branch
- Uncommitted changes
- Commits ahead/behind remote

### Environment
- Node.js version
- Required env vars present (don't show values)
- Supabase connection status

### Database
- Migration status
- Table count

### Dependencies
- Any outdated packages
- Security vulnerabilities

### Services
- Vercel deployment status (if linked)
- AWS CLI configured

## Output Format:
Provide a concise summary table with status indicators.
